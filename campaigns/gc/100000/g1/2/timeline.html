Each fork from JVM start to exit, on the wall clock.
?
Startup is JVM boot and benchmark setup; exit runs from the last iteration to the JVM's exit (with xctrace, it includes saving the trace). GC pauses come from the fork's GC log. With xctrace, counter lanes cover the measurement iterations, which is what xctrace records; cycles are per second, so one busy performance core is about 4–4.5 G. Each counter lane has its own scale. Wheel or pinch to zoom, drag to pan, double-click to reset.
